# Память Claude — bald-logist

Личные рабочие файлы **bald-logist** (`senya.volkov@gmail.com`). Не путать с
`CLAUDE.md` в корне репозитория — тот принадлежит автору проекта (Vasily) и
описывает общие правила работы в проекте.

## Зачем

Сессия Claude Code живёт в одноразовом контейнере: он поднимается из свежего
клона репозитория и удаляется после работы. Всё, что не закоммичено, исчезает.
Ровно так был потерян `SESSION_CONTEXT.txt` — он стоит в `.gitignore`, лежал
только на локальной машине и пропал вместе с ней в августе 2026.

Эта папка — то, что переживает любую машину: она в git, а значит на GitHub.

## Что где

| Файл | Что внутри | Как обновляется |
|------|-----------|-----------------|
| `CONTEXT.md` | Текущее состояние: над чем идём, где остановились, открытые вопросы | Перезаписывается — всегда актуальный срез |
| `DECISIONS.md` | Принятые решения и ловушки, на которых спотыкались | Только дописывается, старое не трогаем |
| `SESSIONS.md` | Журнал сессий: дата, что сделано, чем закончили | Только дописывается |

## Как пользоваться

`CONTEXT.md` подключён к корневому `CLAUDE.md` через `@`-импорт, поэтому Claude
читает его автоматически в начале каждой сессии — напоминать не нужно.
Остальные файлы читаются по запросу: «посмотри DECISIONS».

**Правило:** решение считается принятым только после того, как оно записано
здесь и закоммичено. Договорённость, оставшаяся в чате, не переживёт сессию.

## Что сюда НЕ класть

Никаких секретов: `DATABASE_URL`, пароли, токены, ключи API, содержимое `.env`.
Папка коммитится в git, а репозиторий — не место для секретов. Именно из-за
секретов `SESSION_CONTEXT.txt` попал в `.gitignore` и в итоге потерялся. ID
сущностей (договоров, локаций) секретами не являются — их писать можно.
