## 06.08.2026 — память хранится в git, не в Google Drive

**Решение.** Рабочая память ведётся в этой папке и коммитится в репозиторий.
Google Drive для этого не используется.

**Причина.** Claude Code подхватывает память автоматически только из файловой
системы — из `CLAUDE.md` и подключённых к нему через `@` файлов. Из Drive
автозагрузки нет: каждую сессию пришлось бы отдельно просить сходить в папку,
и один раз забыв — работать без контекста. Плюс в Drive нет версионирования и
связи записи с коммитом кода. Репозиторий уже лежит на GitHub и пережил потерю
ноутбука — этого достаточно, отдельное облако проблему не решает.

**Следствие.** Секретам в папке памяти места нет: `DATABASE_URL`, пароли,
токены, содержимое `.env`. Иначе папку придётся исключить из git — и она
повторит судьбу `SESSION_CONTEXT.txt`.

появится память других разработчиков.
